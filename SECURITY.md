# Security Policy

## Reporting a Vulnerability

If you find a security issue in Bot Horizon, please **do not open a public issue**.

Report it privately to the maintainer via GitHub:

1. Abre un issue con el título `[SECURITY]` y **marca la casilla "This is a security issue"** (GitHub lo tratará de forma privada), o
2. Envía un email al mantenedor (ver perfil de GitHub: https://github.com/DakkuaDev)

We'll respond within 7 days with next steps.

## Scope

- `desktop/bot-horizon/plugin.js`
- `gateway/bot-horizon/dashboard/plugin_api.py`

## Out of scope

- Issues caused by local modifications
- Third-party dependencies of Hermes Agent itself
